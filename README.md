# Huzzah Golf Society

A simple mobile app starter for the Huzzah Golf Society members.

## What is included

- A clean Expo/React Native app shell
- Branded home screen using the society logo
- Space for future sections such as:
  - results and leaderboard
  - fixtures and booking
  - members directory
  - handicaps and prizes
  - gallery and news

## Project structure

- `App.js` - application entry point
- `src/screens/HomeScreen.js` - main home screen layout
- `src/data/mockData.js` - placeholder data for fixtures, members, and results
- `src/theme.js` - shared design tokens
- `Huzzah GS.PNG` - society logo asset

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the app:
   ```bash
   npm start
   ```
3. Open the app in Expo Go or an emulator.
